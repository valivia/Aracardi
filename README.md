# 🪶 Aracardi
A web based drinking game

- Web app made using Sveltekit (Typescript/svelte)
- Multiplayer Websocket server made using Axum (Rust)
- Cards largely made and added by various friends

## Features
- PWA (can be installed and works offline!)
- Spectator multiplayer
- Custom themes
- Custom svg player avatars
- Over 300 unique cards
- works with 2-20 players
- Players can be added and removed at any time
